# HenshinLogos - Instalador .deb

**HenshinLogos** es una aplicación de escritorio para el estudio bíblico avanzado: leer la Biblia en múltiples versiones, consultar comentarios y diccionarios, buscar con precisión, crear y proyectar presentaciones, y organizar tu trabajo de estudio.

---

## 📥 Instalación (Linux Debian/Ubuntu/Mint y derivados)

Puedes instalar HenshinLogos de dos formas:

### Opción 1: Instalador automático (recomendado)

```bash
wget https://raw.githubusercontent.com/HenshinLogos/HenshinLogos_for_Linux/main/install_henshinlogos.sh
chmod +x install_henshinlogos.sh
./install_henshinlogos.sh
```

### Opción 2: Manual

1. Descarga el último `.deb` desde [Releases](https://github.com/HenshinLogos/HenshinLogos_for_Linux/releases/latest).
2. Instálalo con:
   ```bash
   sudo dpkg -i henshinlogos_5.1_amd64.deb
   ```

Si hay errores de dependencias, ejecuta:
```bash
sudo apt --fix-broken install -y
```
